# 學年、班級與重修生管理

## 管理員操作

1. 在「帳號管理」新增或編輯帳號，設定學期（例如 `115-1`）與班級。學年從學期前段篩選，不需重複維護兩個欄位。
2. 「批次匯入」可為整批名單指定學期、班級。每行格式為 `學號,姓名,Email`；成功建立的學生立即啟用，首次登入須修改初始密碼。請下載本次初始密碼清單。
3. 期末「學期封存」停用該學期學生，保留帳號、師生指派及學習歷程。
4. 重修生以相同學號重新匯入新學期與班級：停用或軟刪除的學生會恢復原 ID、重新啟用並產生新初始密碼。歷史學期與紀錄保留。教師、管理員帳號不會被學生匯入功能還原。
5. 已啟用的重複帳號會略過；需要轉班或改學期時使用「編輯」。目前一個學生每學期一個班級，登入後新紀錄歸於帳號目前學期。
6. 在教師帳號的「學生」操作中指派學生，教師才能查看其資料。

## 教師查看進度

「學習分析」提供學年、學期、班級篩選與學生名單，包含尚未開始學習及停用的學生。跨學期查詢時，同一學生按學期分列，總學生人數則去重。

點選學號可查看該學生該學期的測驗、作業、AI 助教互動與已記錄時間。測驗週次代表曾有測驗成績的週數，作業完成週次代表已有作業評分的週數，不代表僅開啟頁面就完成課程。名單與總覽平均分數涵蓋測驗及作業事件；個人分析的作業平均依各週最新作業分數計算。

登入學生的測驗交卷與成功完成的 AI 對話現在會自動寫入紀錄。未登入的公開測驗仍可練習，不會綁定學生。過去未曾寫入的活動無法回補；時間只顯示實際寫入的 duration，並非完整在線時數。

## 升級與歷史資料

後端啟動時執行可重複的加欄位遷移，新增班級、學期學籍快照與學習事件學期索引，不重建既有帳號。正式部署前先備份運行中的 SQLite 資料庫，再更新後端及前端。

舊學習事件缺乏可靠學期資訊時保留為「未分類」，不根據學生目前學期猜測歷史學期。未分類紀錄可在不限制學期、班級時於名單查看。修改帳號目前學期不會搬動歷史事件。

這次修改提供管理功能，不代表正式學生名冊已匯入、分班或已完成教師指派。正式站需部署後以真實名冊核對開通狀態。
